integrações entre serviços e regras de negócio complexas.

com leitura técnica de **APIs, logs, filas e banco de dados**. Construo automações Web e de API que dão mais segurança às entregas

Trabalho próximo de engenharia, produto e negócio, tratando qualidade como decisão sobre **risco, cobertura e estabilidade**.

## Abordagem

- **Qualidade desde o refinamento:** critérios de aceite claros e riscos mapeados antes do desenvolvimento.
- **Cobertura orientada a risco:** prioridade para fluxos críticos e impacto no negócio, não para volume de casos.
- **Pirâmide de testes:** base forte em API e integração; E2E reservado para jornadas críticas.
- **Causa raiz, não sintoma:** defeitos documentados com evidência, passos reproduzíveis e impacto.
- **Decisão com dados:** métricas como defect escape rate e DORA para orientar o time.
- **IA com senso crítico:** ganho de produtividade sem abrir mão da validação humana.
